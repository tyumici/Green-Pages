#### User Stats

- dose: Current dosage level
- lifetime_dose: Total accumulated rem
- deaths: amount of times the user has died
- prestige: for the immortals...

#### radiate

Allows the user to gain a level of rem every four hours. When exceeding 100K rem, the user will die and be timed out for 10s in Tyumici's chatroom.

#### geiger

Outputs the users radiate stats. This includes: Current REM, Lifetime REM, Deaths, Prestige.

Parameters
- optional: provide a valid twitch username (!geiger username) to see the given users radiate stats

#### radleader

Displays the current leaders for Current REM, top six.

#### deathleader

Displays the current leaders for Deaths, top six

#### doseleader

Displays the current leaders for Lifetime REM, top six

#### atomize

For the immortals, you will know when to use this...

#### irradiate

For the worthy, you will know when to use this...

#### radcommands

Lists out all of the above radiate commands

### Crust Suite

Available in channels: [BrighterMalphon](www.twitch.tv/brightermalphon)

#### crust

Discerns how crusty you are, from 0% to 100%

#### crustleader

Leaderboard of whom has been the crustiest by top percent

#### crustavg

Leaderboard of whom has the highest average crust rating

#### lifetimecrust

Outputs the users crust stats. This includes: Current Crust, Lowest Crust, Highest Crust, Average Crust, Times Checked
